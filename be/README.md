# Backend PickaThrift

Direktori ini disiapkan untuk backend PickaThrift dengan ExpressJS dan MongoDB sesuai rubrik
Regular Mode.

Belum ada aplikasi, dependensi, skrip, atau variabel lingkungan yang dibuat. Saat digarap,
tambahkan `package.json` dengan nama `@pickathrift/be` supaya ikut terbaca pnpm workspace di
root, lalu sediakan skrip `dev`, `build`, `test`, dan `typecheck`.
