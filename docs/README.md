# Dokumentasi PickaThrift

Dokumen analisis kebutuhan, analisis fitur, rancangan API, dan bukti pengujian Postman untuk Milestone 1 tersimpan di Google Drive:

- [Folder dokumen proyek PickaThrift](https://drive.google.com/drive/folders/18fWD-o-8HaH5uzsJtjpsghzn-5u93bpv?usp=sharing)
